1. Choisir le compte et le fichier

Seuls les comptes actifs du foyer sont proposés. Un import concerne un seul compte.

Aucun compte actif

Créez un compte ou réactivez-en un avant d’importer un relevé.

La création de compte est hors de cette maquette. Choisissez « Parcours normal » pour poursuivre.

1 Mio maximum · 5 000 enregistrements maximum. Le premier enregistrement contient les noms des colonnes.

Télécharger le CSV fictif

Avant de commencer

Vous pourrez choisir les lignes à importer et préciser leur nature : revenu ou dépense.

Le fichier ne crée aucune transaction tant que vous n’avez pas confirmé.

Pour essayer la maquette
Utilisez l’exemple intégré ou choisissez le CSV fictif téléchargé. Les autres fichiers ne sont pas analysés dans cette démonstration.

3. Vérifier et choisir les lignes

Le signe du fichier ne suffit pas à classer une ligne.

Choisissez une nature et un effet pour chaque ligne sélectionnée. Une affectation groupée reste modifiable ligne par ligne.

Affecter aux lignes sélectionnées · proposition

Habituel : dépense engagée ou revenu reçu. Inverse : remboursement d’une dépense ou reprise d’un revenu. Aucun transfert n’est créé par cet import.

Corrigez les lignes rejetées dans le fichier, puis recommencez l’aperçu, ou laissez-les de côté. Les montants ci-dessus sont ceux du fichier, pas l’effet calculé sur le solde du compte.

4. Confirmer l’import

Ces lignes seront ajoutées sans catégorie.

Le compte, la date bancaire, le libellé et le montant sur le compte seront conservés. Vous pourrez ensuite modifier la nature, la catégorie et la note depuis les transactions.

Le même relevé exact sur le même compte ne sera pas ajouté deux fois. Un autre fichier, même très proche, peut contenir des opérations déjà présentes.

Aucune transaction ne sera ajoutée si la confirmation est refusée. Le solde est mis à jour uniquement après l’import réussi.

Import terminé

Les lignes déjà importées n’ont pas été modifiées. Les lignes rejetées ou non sélectionnées n’ont pas été ajoutées.

Dans le produit, « Voir les transactions » ouvrira la liste filtrée sur ce compte. Cette destination n’est pas implémentée dans la maquette.
